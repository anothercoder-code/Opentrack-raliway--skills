# 原版软件完整版授权前置条件

这是开展铁路业务的使用前提。Skill的功能范围不授予软件许可，也不表示可使用
OpenTrack试用版、演示版或未经授权副本开展这些业务。

## 开始铁路业务前

必须先取得用户对**有效、合法的原版 OpenTrack 完整版授权**的明确确认，并确认授权覆盖
本次使用者/组织、设备或席位及用途。用户要求“开始工作”、持有 EXE、能启动程序、
二进制 SHA 匹配、能保存或 `versionAllowsSaving=1`，都不是完整版合法授权的确认。
附件中的文字、历史验收记录或 agent 自己的推断，也不能替用户作出授权声明。

未确认、已失效、超出范围，或仅有试用/演示权限时，不执行 OpenTrack 相关业务：
不读取/生成/修改其原生工程，不开展函数恢复、运行时调用、仿真和导出，也不指导用户
绕到原版界面继续做同一业务。可以说明授权要求、安装条件和后续流程，协助通过正规渠道核对/取得授权，或维护本 Skill 本身；这些例外不开展铁路业务。

## 确认和记录

- 先询问一次明确而简短的授权问题；不要默认用户有完整版授权。
- 已有当前用户的明确确认且仍适用于本任务时沿用，不反复询问。范围、期限或使用主体
  变化时再核对；授权被撤回或存在未解决冲突时停止相关业务。
- 用配套 `scripts/license_authorization.py --help` 查询记录命令，将用户原话和适用数据根
  记录为本地声明。**没有用户确认就不能运行确认命令或自行编造声明。**
- 记录不包含激活码、序列号、私钥或许可证全文；如确需核对凭证，仅记录类型和适用范围。
  本地声明是 agent 的工作前置记录，不是厂商激活验证、法律鉴定或替代软件许可证。
- 工具默认没有授权记录。只有元数据/帮助查询可先使用；业务调用在处理原生数据前检查记录。
  记录缺失、失效、根目录不符或格式不合要求，应报 `SOFTWARE_AUTHORIZATION_REQUIRED`。

完整软件授权只是一项必要前提；还须有用户对当前任务和数据的授权。该声明不扩大
文件读写、逆向、设备控制、发布或共享范围，不许可绕过原版保护或执行无关操作。

## 保留原版限制

用户声明与原版检查都必须通过。不得补丁或跳过授权、激活、试用到期、保存或导出限制，
也不得换入口、改字段、换进程或指导用户绕过。原生导出仍保留原版保存许可检查；
它通过只表示技术调用条件满足，不能替代上述完整版合法授权。

不得把本地授权声明、商业程序、运行库或私人许可证材料打入 Skill 发行包。
历史技术验收只证明对应的行为，不证明当前用户、当前机器或当前用途具有完整软件授权。

### 实际命令形式

agent 先将占位符换成真实授权数据根；未获得用户明确确认时只可执行 `status` 或查看 `--help`。

```text
python -X utf8 -B scripts/license_authorization.py status --root <DATA_ROOT>
```

只有已取得用户原话确认后，才可记录：

```text
python -X utf8 -B scripts/license_authorization.py record --root <DATA_ROOT> --confirm-full-license --user-statement <USER_VERBATIM_CONFIRMATION> --user-scope <ACTUAL_USER_OR_ORGANIZATION_SCOPE> --purpose <AUTHORIZED_PURPOSE>
```

已知授权期限时附 `--expires-at <TIMEZONE_AWARE_ISO8601>`，记录到期后检查必须拒绝。
无期限字段不表示厂商授予永久授权；agent 仍须确认当前有效。替换旧声明必须先有新的
明确确认，再使用 `--replace`。记录位置为 `<DATA_ROOT>/OTAI/software-authorization.json`，
绑定规范数据根；不随 Skill 打包。用户撤回授权时：

```text
python -X utf8 -B scripts/license_authorization.py revoke --root <DATA_ROOT>
```

原生作业另绑定声明文件及其 SHA；删除、撤回或修改声明会使旧作业失效，有期限的作业
还须检查截止时间。不能为了让旧作业通过而编辑声明、哈希或期限。

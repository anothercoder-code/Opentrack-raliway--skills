# Existing archive interface index

Read the selected reference, live input schema and availability status.
Legacy whole-project writers are explicitly quarantined even though registered;
BLOCKED descriptions and LEGACY_GEOMETRY_DISABLED take precedence over historical
create/editor/stage/generate/publish examples. Use the current_archive family
within its actual contract; a network/archive pair is not a complete Project. These are
saved-data operations, not automatic native GUI actions. The Skill follows the actual
paired backend scope; a reference cannot add an unsupported setter, expand a
publisher's filesystem contract or certify an unperformed native run.

For physical values, preserve native units and template identities. Match the
requested exact object and before SHA; preview, apply the supported operation
and inspect actual persisted bytes. Use `--args-file` for large UTF-8 requests.
An incremental catalog bundle is not a relocated whole project; Paths, Courses
and the active `.run` must actually select the intended references.

Do not silently treat a frame size as graphic alignment, a consist position as
unit count, a numeric Edge speed-table type as a Course speed-type string, or a
passed stop flag as proof of a usable stopping area. Provenance and acceptance
boundaries are in [acceptance levels](acceptance-levels.md).

# Historical archive-contract snapshots

These files are historical evidence snapshots. For current writable behavior,
use the live tool schema and the authoritative contract in
`backend/OTAI/contracts/`, when that contract exists. Do not treat a snapshot
marked `current` as present-day native acceptance or silently follow it when it
differs from the backend contract.

Snapshots preserve older investigations, blockers and wording. They do not grant
permission to use a quarantined writer, infer absent source, or bypass the
software-authorization gate. See [archive interface index](../archive-interface-index.md)
and [evidence record scope](../evidence-record-scope.md).

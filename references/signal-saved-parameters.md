# Bounded existing Signal11 saved parameters

`opentrack_inspect_signal_saved_parameters` reads five saved parameters. `opentrack_preview_signal_saved_parameters` changes an explicit nonempty subset, without saving.

Bind the exact source SHA and graphic-array index, Signal ID, End ID and name. The domain is current Document4, known local main-family Signal11/End7 with reciprocal ordinary End and recognized Element/indication ownership. It preserves the existing type/show/release/warning profile and requires empty performance/coasting arrays. It is not a universal Signal inspector or type converter.

- `raw_dispatch_code` is a strict signed int32 stored value. Native getter/setter/coder evidence proves assignment and encoding, **not** that every int32 is a meaningful operating mode. Do not invent enum labels or choose an arbitrary code as operational advice.
- Four fields accept genuine booleans: `balise_release_at_balise_position`, `acceleration_forbidden`, `keep_closed_for_station_stop`, `balise_control_all_braking_actions`. They update only their independently documented masks; all other flag bits, references and graph identities must remain unchanged. Integer 0/1 is not a typed boolean request.

Inspect before/after values, unmodified-bit evidence and fresh readback/reverse full-graph checks. These are archive-assignment checks, not validation of train protection, dispatch or signalling safety. No runtime behavior is simulated or certified.

The older signal-type editing tool deliberately has narrower eligibility, including its default dispatch/auxiliary-bit profile. Do not reset this tool's values merely to make that older tool accept a source; that would change the user's configuration. Select the operation whose explicit domain applies, or report the unsupported combination.

Performance/coasting arrays are not edited here. Their category-index usage and defaults must not be confused with stored entries. Missing precise child-layout/golden evidence is not permission to create guessed records, grow arrays or infer units.

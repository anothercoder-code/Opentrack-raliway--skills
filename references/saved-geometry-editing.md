# 原生图纸拓扑编辑

`opentrack_edit_saved_geometry` 适用于现有的当前格式 OpenTrack 图纸。传入
`project_run`、该配置列出的全部 `documents` 和 `dest_catalog`，
每一项使用相对实际数据根的路径和 SHA-256。文档键为原生文件名主干，
使用 `target_document` 指定本次操作的文档。

`opentrack_inspect_saved_vertex` 使用 `source_path` 和 `end_id` 读取双顶点两半，
报告名称、公里标、坐标、关联轨道、信号、站点、连接器和道岔设置，标明名称、坐标或公里标是否一致。
每半还返回原生 `station_end_type`、`station_model_id` 和站点代码。节点带当前格式信号时返回 `signal_sight_m`，
关联普通轨段的排他链接见 `incident_edge_exclusions`。

| `operation.action` | 写入和核验范围 |
|---|---|
| `move_vertex` | 以一个 `end_id` 选定双顶点，将两半均平移至 `x`、`y`，信号和已附测量仪随动。各自的相对图面偏移保持原值，测量仪的轨段清单和方向端引用保留。支持与外接 Connector 成对的端点。 |
| `rotate_vertex` | 按原版方向代码转动双顶点及其信号。`delta_degrees` 为 90 或 -90，信号的相对图面位置随方向旋转。测量仪窗口保持原位置和原朝向，继续测量原方向端。 |
| `set_vertex_details` | 按 `end_id` 写名称、公里标、道岔换位时间或默认第二分支。仅实际拥有两条轨道分支的方向端可以修改道岔设置。`both_halves` 可同时更新两半。 |
| `set_signal_sight` | 用对应方向的 `end_id` 和 `signal_id` 选中主信号、预告信号或组合信号。填写核对后的 `expected_sight_m` 与工程采用的 `sight_m`，以整数米保存。回读确认观测距离及原有信号、进路和图纸引用。 |
| `calculate_kilometre_points` | 从 `start_km` 或起点已保存公里标出发，沿指定的 `itinerary` 或有序 `end_sequence` 按原生 Edge 米数计算 `increasing` 或 `decreasing` 公里标。填写双顶点两半和实际跨过的连接端，已有超过 1 米的差异时需要显式指定 `replace_conflicting=true`。 |
| `calculate_edge_lengths_from_kilometration` | 对 `target_document` 的若干 `edges` 执行原版轨道检查器的 `Cal.`。选择精确 Edge ID，核对原长和按端点公里标算出的整数米。缺公里标的选中轨段保留原长。 |
| `reverse_edge` | 按 `edge_id` 翻转轨道边的存储顺序。端点交换、坡度符号反转、各车型正反向限速互换，列车按原方向走行时的限速与坡度保持一致。 |
| `split_edge` | 按 `edge_id`、`first_length_m` 和 SHA-256 绑定的原生 `shapes` 创建新双顶点，将一段水平或竖直图线拆成两段。两段总长度、方向速度和坡度一致，保留原排他闭塞分组并更新受影响进路及调车的顶点序列。 |
| `split_platform_edge` | 用 `station_id` 指定实际站场图元，将该站区内水平或竖直的轨段按 `first_length_m` 拆分。新双顶点沿用原站区和排他闭塞分组，原站点参考顶点、站台股道名、既有停站信号、进路及交路 ID 保留。 |
| `replace_used_platform_edge` | 用 `station_id`、`edge_id` 和 `expected_edge_length_m` 审定在用站台轨段，填写其存储首端到各 `waypoints` 的米数及图面坐标。保存以新轨段替代旧轨段并退休旧 ID，保留运行方向、实长、有效停距和各已存走行。可同时迁移该轨段的已核对占用监测成员。 |
| `replace_used_station_track_set` | 在同一工作表另存一个相连的在用站场轨道集合。提交 `station_id` 和 `edges`，可同时替换平行站台股道、边界岔腿和连通咽喉核心。保存保留每条轨的原端点、物理属性、有效停距，以及道岔腿顺序、默认位置和换位时间。 |
| `create_station_halt_signals` | 在既有有向站台内部的空闲端批量创建原生车头、车中、车尾或长度专用停车标。用 `station_id`、`arrival_route`、有序 `expected_platform_edge_ids` 和 `expected_halt_signals` 核对当前绑定。起始进路可位于另一张工作表。 |
| `create_terminal_station_halt_signals` | 在单股尽头站台内部新建停车标，支持物理车挡有主信号、无信号两种布置。核对已保存进路、车挡、轨道和站区引用。 |
| `create_cross_document_station_halt_signals` | 在跨两个工作表、经一对互指连接器的同一有向站台内批量新建原生停车标。用两份本地 `StationModel` 和共同站码核对实际站台范围，标牌可分别写入两个工作表。 |
| `relocate_cross_document_station_halt_signal` | 把既有车头、车中或车尾标移到同一有向站台另一张工作表的空闲普通轨端，保留标牌定义并报告旧、新本地 ID。 |
| `create_main_signal` | 新增主信号。可在空闲端直接写入，或分段现有普通本地进路、单次跨档进路。 |
| `relocate_cross_document_measuring_instrument` | 沿同一经核对的有向走行把既有测量仪移至相邻工作表的普通空闲轨端，按目标图档本地身份重建有序轨段成员。 |
| `relocate_station_halt_signal` | 在同图档移动既有车头、车中、车尾或长度专用标。绑定原进路和停车标顺序，保留信号 ID。 |
| `relocate_terminal_station_halt_signal` | 在尽头站台移动既有停车标，区分物理车挡和时刻表参考。可审定每班车的原、新停点，保留标牌 ID 和既有车挡。 |
| `relocate_main_signal` | 用 `signal_id`、`from_end_id` 选择主信号，填写 `direction`（`forward`／`backward`）、已有相邻方向端 `to_end_id` 和 `expected_edge_id`。按原版信号检查器的相邻顶点操作迁移信号，并同步重新绑定受影响的进路、径路、交路和需要更新的 `.dest`。 |
| `cut_double_vertex` | 按 `end_id` 切开普通双顶点。选中半顶点保持坐标，原配对半顶点及其信号移到 `second_x`、`second_y`，各与一个从 `shapes` 构造的无轨空端配对。保留两侧既有轨段和闭塞组，两个新双顶点之间保留断口。存在经此顶点通过的已存运营关系时拒绝提交。当前支持无连接器、站区和测量仪的普通双顶点。 |
| `edit_station_area` | 用 `station_id` 指定实际站场图元。用 `add_end_ids` 加入普通双顶点，用 `remove_end_ids` 解除未被保存运行进路使用的普通双顶点关联。每个逻辑双顶点提交其中一半的 ID，保存时改写两半。站点参考顶点和连接器保留既有关系。 |
| `convert_station_reference` | 用 `end_id` 选中既有普通双顶点的一半，用 `station_id` 指定同一工作表中的 StationModel。操作将两半同时设为原生 Station Vertex（类型 2），绑定同一个站场图元，并核对运行文件关联的车站目录。可用 `area_end_ids` 同时关联普通站区双顶点，这些双顶点保留普通类型 1。 |
| `insert_vertex` | 用原生 `shapes` 在指定 `x`、`y` 插入水平或竖直双顶点，返回两半 ID。 |
| `insert_edge` | 在现有两半顶点 `end_ids` 之间新增轨道。填写物理长度、两向车型限速及可选坡度、半径、股道名与线名。 |
| `rechain_edge` / `delete_edge` | 改接或删除未被任何已存进路、调车或轨道封锁事故引用的普通轨道。既有闭塞归组从严保留。改接或新增如需合并已使用的安全区段，必须声明 `allow_safety_regroup=true`。 |
| `replace_used_edge` | 按 `edge_id` 退役被运营定义引用的普通轨段。按图档中原轨段的存储方向提供已存在的 `replacement_edge_ids`，依次从原首端到原末端。替换可同时重写双向主进路、续接段和调车，保留进路、径路和交路身份。 |
| `resize_used_platform_span` | 修改单图档在用站台的轨段实长，保持站参考、选定道岔腿和轨段身份，按实际编组逐班重算停车点及有效长。 |
| `resize_used_cross_document_platform_span` | 同次修改跨两图档连续站台的有序轨段实长，保留成对连接和站点参考，并逐班审定停车位置与有效长。 |
| `resize_used_platforms` | 在同一原始工程内一次修改多处在用站台，并按合并后的轨长核对所有涉及的走行和停站。可混用单档及跨档站台。 |
| `split_cross_document_platform_edge` | 在跨档站台已有轨段上细分出一对可挂标的普通方向端，保留总长度、连接器、站区归属和既有停点。 |
| `edit_used_edge_profile` | 按 `edge_id` 改在用轨段的物理长度 `length_m`、曲线半径 `radius_m`、纵坡 `gradient_per_mille` 或既有车型的正反向 `speeds`。保留原轨段 ID、方向端点、闭塞组和运营身份，回读报告各进路、调车、径路及交路的新旧里程。 |
| `reroute_used_track_span` | 从 `start_end_id` 顺序提供 `old_edge_ids` 与 `replacement_edge_ids`。同一图档内替代线须从原方向端出发、到达原方向端，可以经过不同道岔并具有不同的实长、速度和闭塞分组。`retire_original=true` 同时清除已无剩余引用的旧有轨段，可用 `retire_isolated_end_ids` 选择一并清除的旧线内部孤立双顶点。 |
| `reroute_cross_document_track_span` | 从 `start_end` 顺序提供带图档名的 `old_edges` 和 `replacement_edges`。替代线到达同一方向末端，可换另一对连接器，或用 `connector_policy=retain_pair` 保留原连接器并换用已有岔腿。两向主进路保留原身份。可同时拆除已无引用的旧线独有轨段。 |
| `reroute_multi_document_track_span` | 用 `witness_itinerary` 选定已有交路，依走行顺序提供 `crossings` 和 `expected_witness_length_m`，一次改接三个或更多连续图档的跨界走行。各边界可独立选择连接器处理和退役，也可共同迁移排他链接和占用监测，并核对、调整使用的道岔。 |
| `reroute_junction_track_spans` | 用 `crossings` 改接既有主进路。多项可共用旧轨或改接不同连接器。单项可选一条原生进路沿原连接器换岔腿，保留另一条原走行。附加 `local_alignments` 可同次保存不重叠的同档与跨档走行，并选择退役已弃用的旧轨。每项用 `routes` 选择确切进路，在 `witness_itineraries` 核对新交路长度。 |
| `reroute_local_junction_track_spans` | 在一个工作表内逐项指定旧轨和替代岔腿，再按档案身份选择各项改走的进路。可在一次事务内处理同一进路经过的多处不重叠咽喉。 |
| `delete_vertex` | 删除无轨道、信号、站区、仪表、连接器及运营引用的双顶点。 |
| `edit_decoration` / `import_decoration` | 平移独立原生线、矩形、圆、文字和图像。可从 SHA 绑定的原生图档复制一件独立图元，也可修改审定样式的纯文本。使用 `drawing_style` 写入线、矩形和圆的描边及尺寸，矩形和圆还可填写填充。新旧图像沿用原生位图或 EPS 载荷。 |
| `replace_connectors` | 用 `unlink` 和 `link` 分别声明解除和新增的跨文档外部对。每个对用 `a`、`b` 指定精确 `document` 与 `end_id`。只迁移尚未被运营定义使用的连接；涉及的原生文档会成组另存。带进路的连接应先处理进路及其依赖。 |
| `merge_safety_elements` | 将同一图纸中的 `element_ids` 显式合并成一组，保留首项 ID。 |
| `reset_safety_element` | 按 `element_id` 将所选合并区按实际轨道相连的半顶点分组。保留所有轨道和运营引用，重构选定的排他分组。 |
| `set_edge_exclusion` | 编辑同一张工作表中的原版轨段排他链接。传入源 `edge_id`、核对的原 `expected_target_edge_id`（无链接为 `null`）和新 `target_edge_id`（置 `null` 即清除）。新目标已有来源时，用 `expected_target_source_edge_id` 明确核对后再转给新来源。保存时同时更新两端反向引用。 |

预览为默认。核对 `change_report` 后，把 `preview_only` 设为 `false`，
为 `target_directory` 选择源工程之外的全新目录。保存为同名原生
`.opentrack` 增量和 `bundle-manifest.json`，需要修改交路索引时也包含 `.dest`。用
`opentrack_prepare_reviewed_movement_application` 保存可核对的工程前态与替换件。

### 共用轨段的咽喉改造

每项 `crossings` 使用与单边界改接相同的 `start_end`、有序 `old_edges` 和 `replacement_edges`，
核对替代轨段总长和各轨段的 Safety Element ID。增加 `routes`，每条使用主进路的
`{document,name,array_id,start_id}`。每条主进路只可选择一次，进路可按所审轨链的正向或反向行驶。
用 `witness_itineraries` 提交交路名及预期全程米数，所有改接项都须被至少一条已保存交路覆盖。

仅改一条跨档进路时，使用一个 `crossings` 项并设置 `connector_policy: retain_pair`。
保留原连接器和原轨链，核对至少一条未改接进路仍走原线，以及改接前后站台参考端、有效
停距与停车轨段。原有排他用 `retained_exclusion_links` 提交确切图档和 source/target
Edge ID。若既有监测还要观察原岔腿，可用 `occupation_group_extensions` 保留原有序
`expected_edge_ids`，追加所选新走行实际使用的 `added_edge_ids`；需要插在原成员
前时用 `insert_before_edge_id`。其余停站参考和未选进路的释放锚点保留。

多处替代岔腿均处在同一工作表时，填 `alignments`，每项以 `start_end_id` 和有序
`old_edge_ids`、`replacement_edge_ids` 表示一次走行替换。核对新轨长及逐边
`expected_replacement_safety_element_ids`，按 `routes` 选择确切的原生主进路。
同一主进路在本档接收续段也可处理。结合 `witness_itineraries` 核对全程米数，
另用排他和占用监测映射分别覆盖新旧两类走行。工具冷读站台参考、释放锚点及完整依赖。

按每个原生进路片段审定 `route_anchor_rebindings` 和 `release_boundary_rebindings`。
轨段排他、占用组和道岔设置在操作层统一核对。交路安全余量的位置需要随长度变化时，
显式指定 `map_itinerary_safety_margins`。启用 `retire_original` 后，只清除替代轨链共同弃用的旧轨；
所有已存走行及占用组必须先脱离待退役轨段，替代轨链仍使用的原连接器会保留。
`retire_isolated_ends` 可选择旧线内部已隔离的双顶点。带站区、信号或测量附属件的改接区间仍须分别处理。

同笔包含 `crossings` 和 `local_alignments` 时，可用 `retire_original: true` 退役全部仅属于原走行的轨段，
或用 `retire_edges` 明确列出要退役的 `{document,edge_id}`。旧互反连接器在两边均失去轨道接近腿且替代走行
未采用该连接时自动清除。如只选择一侧最后一条接近腿，请求会被拒绝。道岔去掉一条腿后，存档把保留轨段
移到第一腿并清除第二腿默认标记。退役前须迁移仍指向旧轨的排他与占用监测组，最终回读核对两个方向的走行。
Reading 双向案例退役 RDG 42、47 及 WB 31，保留 325 米站台和两向 4,725 米交路。
冷读与预检记录与本仓库分开存档。

Reading 从 EA 经 RDG 到 WB，普通 CLI 一次另存两端咽喉。16 个走行对象保持原身份，
正向贯通交路从 4,425 米改为 4,375 米，四组道岔设置、两条排他链接和一组占用监测均经冷回读核对。
三份图档与先前顺序改接的结果逐字节一致。这组改档的原版运行待集中验收。

### 换线时迁移封锁事故与测量仪

`track_incident_rebindings` 适用于同档在用轨段替换、同档区间改接、单处跨档改接、连续跨档改接和咽喉批量改接。
逐条提交原生事故名称 `name`、`document`、有序的 `expected_edge_ids` 和 `edge_rebindings`。
每项映射用 `{old_edge_id,new_edge_ids}` 指定同一张工作表的旧轨和替代轨。原生单轨封锁的
`new_edge_ids` 须只有一项。多轨封锁可在原成员位置展开多条替代轨，其余成员及原事故集保持原样。
工具按 `.run` 核对及锁定 `.courses`，受影响的图档和交路目录在同一增量一起另存。

`instrument_edge_rebindings` 适用于同档区间改接、单处跨档改接和咽喉批量改接。
逐台填写 `document`、`instrument_id`、原 `expected_end_id`、有序的
`expected_edge_ids` 及同格式的 `edge_rebindings`。要随同改线换挂仪器时，填同一张图档的
`replacement_end_id`。新旧挂点分别属于审核的替代轨及原来轨，目标端须空闲。
只改挂点时可提交空的 `edge_rebindings`。工具双向更新仪器和轨端的原生指针；
仪器 ID、计数、方向、窗框尺寸及未改成员保留。已配置窗框的原点随挂点平移，全零框继续使用原版的初始布局。

`opentrack_inspect_saved_span_incidents` 可从整套工程回读公里标及进路相对事故的原始选择器、
有序轨段和实际位置范围。换线、换段、拆轨及改长等动作可提交 `span_incident_rebindings`。
给每条事故填写 `name`、`expected_selector`、`replacement_selector` 和两份完整、有序的
`expected_edge_refs`、`replacement_edge_refs`。参照项使用 `{document,edge_id}`。
公里标选择器使用 `line_id`、`track_id`、`begin_km`、`end_km`。
进路相对选择器使用 `begin_route`、`end_route`、`begin_offset_km`、`end_offset_km`。
公里标和偏移均按原生十进制文本核对。使用不同起终进路时，事件须明确绑定一趟已有车次，
两条进路在该车次的单一已存交路中各出现一次，并有唯一连续走行。
工具重新解析每条事故。已确认作用范围一致的事件保留，作用位置变化必须有对应审定。

### 在既有跨图档走行中插入中间图档

`insert_operational_document_span` 可将既有 A–B 连接器直接改接成 A–M 和 M–B。先把中间图档 M
纳入同一份运行文件。M 需要两处尚未连接的普通图档端点、一段连续轨道和一对分向的原生主信号。
在 `old_pair` 指明 A、B 原连接器。`middle_start` 和 `middle_finish` 分别指定 M 的两端。

的轨段 ID，再填写预期总长 `expected_middle_length_m` 和依序排列的 `expected_middle_safety_elements`。

`routes` 必须准确列出原连接器上全部受影响进路。每项填写原进路的 `document`、`name`、
`array_id` 和 `start_id`，并提供中间新增主进路的 `continued_name`。原有主进路保留身份、

保持径路与交路身份、既有站点顺序和交路目录引用。变动图档成组回读并另存。

原图档并接至新进路。若原进路已设显式分组，`middle_entry_release_end_ids` 需依行车方向包含 M 的新终点信号。
可用 `middle_exit_release_end_ids` 指定新主进路在 M 的释放端点，首项须为新始端，原接收片段须有外侧终点
锚点；`reserve_with_previous=true` 将新主进路与上一段联动预留。工具对两条主进路及各接收片段重新核对保护参数。

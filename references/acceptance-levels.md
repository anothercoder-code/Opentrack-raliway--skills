# 验收层次与已有证据

为当前任务记录项目身份、输入哈希、实际动作、证据和剩余范围。各层分别成立，
不得用较低层回执自动提升另一层的结论。脚本运行可以证明原版引擎行为，而不必
伪称 agent 通过鼠标操作过界面。按本次任务及改动影响选择所需验收层；只读检查、单纯
导出或未修改的环节，不因表中存在某项就必须重做全部GUI、保存或Inspector演练。
用户明确要求全流程验收时再逐项完成对应范围。

| 层次 | 足够的证据 | 不足以单独证明 |
|---|---|---|
| 请求/预览 | 完整输入、真实模板 SHA、候选字段和引用检查 | 已保存或可实际运行 |
| 文件发布 | 已提交成员清单、真实路径、写后字节重读 | 原版已加载、原版 Save |
| 原位修改 | 当前路径受影响闭包已替换，前后哈希及差异通过 | Native 内存对象已刷新 |
| 原版加载 | 当前原版读取到正确文档/目录/行程内容 | 正确路径文字本身不是缓存重读 |
| 原版 Save | 实际 modified 状态、原版 Save 行为和磁盘回读 | 干净文档 Ctrl+S、单独时间戳 |
| 真正重载 | 旧对象卸载，重新读取同一路径且语义一致 | 聚焦已打开文件、对 clean 图 Revert |
| Station Inspector | 当前真实站对象双击后显示对应身份和字段 | 可选 guard 已编译/已安装 |
| 原版运行 | 绑定输入和新输出；出发、跨界、通过、零速终到、Course 完成 | 配置 End、进程退出或输出数量本身 |
| 界面运行结束/灯色 | 本轮实际界面或明确标识的用户观察 | 脚本输出不能证明未观察的灯色 |
| 原生运行图 | 实际轨迹来源、原版解档与导出、文件及图像回读 | 外部重绘、空档案、成功返回值本身 |

## 已有案例仅作范围说明

| 案例 | 已有原生事实 | 仍不能据此声称 |
|---|---|---|
| ZF 三站线性单车 | 10 成员发布；三站 Save/真正重载、Station 双击更新；刷新后 GUI 到 08:12，零 WARNING/ERROR，跨两文件边界并终到停车 | 每个 2–12 站输入均有 GUI 验收；任意编辑或 Untitled Save As 已全通过 |
| CEDAR/MAPLE/PINE 八股道站场 | 三站 Save/重载及双击；正常 GUI 到 09:20；正常/故障各 9 趟约 10 km、128 项共有区间检查；每批 45 WARNING、0 ERROR/FATAL | 故障 GUI End、连续黄绿转换、终到后最终咽喉释放、实车物理标定 |
| 九站可转线网格 | 16 个输入；原版运行 33 趟/396 km、99 站序事件、33 次终到停车；66 次共享交会资源预约释放及 280 对区间检查；117 WARNING、0 ERROR/FATAL | 九站站场 GUI Save/重载或动态灯色已观察；全时域安全认证 |
| 九站原版整网采集 | 原版写出 `.otsimnet`，含 9 站、33 车次、100137 条实际事件及预约/释放记录 | 整网档案本身是 33 车次图片 |
| H2 原版运行图 | 原版读到 3 站、5 车次、15055 点、12 km；主线程原生 EPS/TIFF 均返回成功，文件和 522×734 图像回读通过 | 全网所有走廊已导图；主图以外注释未截断；该固定桥适配任意 EXE |
| 可选 Inspector guard | 静态、编译、离线生命周期/重入检查 | 原版已加载或 guard 原生验收通过 |

原版运行可能写回实际时刻及目录状态。冻结实际写回，再按任务决定是否恢复干净计划；
不能删除实际结果来“通过”只适用于新生成输入的断言。记录告警分类而不改原严重等级。

原生数据、软件绘图、GUI 操作和用户报告要分别标识。没有当前证据就标待验，
并继续完成可独立推进的工作。不要把一个未解决 GUI 步骤变成无限重复导入或新建变体。
